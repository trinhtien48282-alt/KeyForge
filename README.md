# KeyForge 🔐



An offline password generator and encrypted password manager built with Python and PySide6.



## Planned Features


- Secure password generation
- Configurable password length and character sets
- Password entropy analysis
- Encrypted local credential vault
- Windows desktop interface
- Offline-first operation



## Technology Stack



- Python
- PySide6
- pytest
- Git



## Project Status



🚧 Under development. Features are planned and may not be implemented yet.



## Security Notice



KeyForge is an experimental personal project. Do not store real credentials in it until the vault implementation has been reviewed and tested.
